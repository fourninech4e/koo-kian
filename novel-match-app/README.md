# คู่เขียน (Koo Kian)

แอปเขียนนิยายร่วมกับคนแปลกหน้าแบบผลัดกันเขียน + จับคู่ตามสไตล์การเขียน
แนวคิด: **ReadAWrite ผสม Tinder**

- ปัดหาคู่เขียนแบบ Tinder โดยระบบคำนวณ "ความเข้ากันได้" จากแนวเรื่องที่ชอบ
  และการวิเคราะห์สไตล์การเขียนจากตัวอย่างงานเขียนของแต่ละคน (ความยาวประโยค
  ความยาวคำ ความหลากหลายของคำศัพท์)
- ถูกใจกันทั้งคู่ → แมตช์ → เริ่มเขียนนิยายด้วยกันได้ทันที
- เขียนนิยายแบบผลัดตา (ตาใครตามัน ระบบล็อกไม่ให้แซงคิว)
- มีหน้าฟีดอ่านนิยายของคู่เขียนทุกคนในระบบ แบบ ReadAWrite

โปรเจกต์นี้เขียนด้วย **Node.js ล้วน ๆ** (ใช้แค่โมดูลมาตรฐานของ Node เช่น
`http`, `fs`, `crypto`) จึง**ไม่ต้องรัน `npm install` เลย** เก็บข้อมูลเป็นไฟล์
JSON ธรรมดาไว้ที่ `data/db.json` (จะถูกสร้างอัตโนมัติตอนรันครั้งแรก)

## วิธีรัน

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป

```bash
node server.js
```

หรือ

```bash
npm start
```

แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

ต้องการเปลี่ยนพอร์ต:

```bash
PORT=8080 node server.js
```

## โครงสร้างโปรเจกต์

```
server.js          เซิร์ฟเวอร์หลัก (routing + REST API + เสิร์ฟไฟล์ static)
lib/store.js        อ่าน/เขียนฐานข้อมูล JSON
lib/auth.js          จัดการรหัสผ่านและ session (cookie)
lib/match.js         คำนวณคะแนนความเข้ากันได้ของสไตล์การเขียน
public/              หน้าเว็บทั้งหมด (HTML/CSS/JS ฝั่งไคลเอนต์)
data/db.json         ฐานข้อมูล (สร้างอัตโนมัติ, ลบทิ้งได้ถ้าอยากเริ่มใหม่)
```

## หน้าในแอป

| หน้า | คำอธิบาย |
|---|---|
| `/index.html` | เข้าสู่ระบบ / สมัครสมาชิก |
| `/profile.html` | ตั้งค่าโปรไฟล์ แนวที่ชอบ และตัวอย่างงานเขียน |
| `/discover.html` | ปัดหาคู่เขียน (แบบ Tinder) |
| `/matches.html` | รายชื่อคู่ที่แมตช์กัน + เริ่มนิยายเรื่องใหม่ |
| `/story.html?id=...` | ห้องเขียนนิยายแบบผลัดตา / อ่านนิยาย |
| `/feed.html` | ฟีดอ่านนิยายทั้งหมดในระบบ |

## หมายเหตุเรื่องความปลอดภัย (สำหรับ production จริง)

ตัวอย่างนี้เน้นความง่ายและไม่พึ่ง dependency ภายนอก เหมาะสำหรับรันทดลอง/เดโม
หากจะนำไปใช้งานจริงควรพิจารณาเพิ่มเติม เช่น:
- ใช้ HTTPS จริงและตั้ง cookie เป็น `Secure`
- ใช้ฐานข้อมูลจริง (PostgreSQL/MongoDB) แทนไฟล์ JSON เพื่อรองรับผู้ใช้จำนวนมาก
- เพิ่ม rate limiting และการตรวจสอบเนื้อหาที่ไม่เหมาะสม
- เพิ่ม WebSocket แทนการ polling เพื่อแจ้งเตือนตาเขียนแบบเรียลไทม์
